The pipeline enforces itself.

Agents propose. Hooks decide. Every phase emits a verdict recomputed from artifacts — never trusted.

Hook-gated pipeline

PreToolUse and SubagentStop hooks gate every skill transition. A phase can't advance on a claimed pass — the gate recomputes passed from the artifact itself.

Dedicated subagents

Every phase spawns isolated author + reviewer subagents with file-map partitions — fresh context, zero drift.

Derived state machine

Runs partition per ticket under a gitignored .acs/state-machine/ — resumable, auditable, outside the tree.

Verified delivery

TDD executors write failing tests first; a two-layer eval suite — free calibration checks in CI, paid session graders at release — grades routing and behavior, not vibes.
